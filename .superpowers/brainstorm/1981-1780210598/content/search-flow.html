搜索功能完整流程

用户从输入到查看结果的完整交互链路

移动端流程

1. 首页
点击搜索框 → 跳转搜索页
→
2. 搜索初始态
热搜标签 + 搜索历史
→
3. 输入态
实时建议下拉
商品名 + 热搜词
→
4. 结果态
商品列表 + 排序Tab
+ 筛选浮层

Web端流程

1. 导航栏
输入关键词
显示建议下拉
→
2. 搜索结果页
左侧筛选面板
右侧商品网格
→
3. 筛选/排序
左侧选分类/品牌
顶部选排序方式

后端数据流

搜索请求
GET /api/v1/products
?keyword=xx&sortBy=price
→
记录关键词
异步写入
cms_search_keyword
→
返回结果
分页商品数据
+ 总数
热搜API
GET /api/v1/search/hot
返回 Top 10 热搜词
→
建议API
GET /api/v1/search/suggest
?keyword=xx
