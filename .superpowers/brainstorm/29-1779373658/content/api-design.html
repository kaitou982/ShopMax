Phase 1 API 设计

统一前缀 /api/v1/community（C端）和 /api/v1/admin/community（后台），网关已有路由配置

📱 C端 API（移动端消费）
笔记
GET   /notes?page=&size=&tab=recommend|following
GET   /notes/{id}
POST  /notes
PUT   /notes/{id}
DELETE /notes/{id}
互动
POST  /notes/{id}/like
POST  /notes/{id}/favorite
GET   /notes/{id}/comments?page=&size=
POST  /notes/{id}/comments
DELETE /comments/{id}
用户
GET   /users/{id}/notes?page=&size=
GET   /users/me/favorites?page=&size=
🖥 后台 API（管理端消费）
内容审核
GET   /admin/community/notes?status=&page=&size=
GET   /admin/community/notes/{id}
PUT   /admin/community/notes/{id}/audit
数据统计
GET   /admin/community/stats/overview
