技术栈 & 项目结构

pnpm monorepo，三包共享 API + Store

项目结构
shop-frontend/ ├── pnpm-workspace.yaml ├── package.json ← 根 package，scripts 编排 ├── tsconfig.base.json ← 共享 TS 配置 │ ├── packages/ │ ├── shared/ ← 共享层 │ │ ├── package.json ← @shop/shared │ │ ├── src/ │ │ │ ├── api/ ← 11 个 API 模块 │ │ │ ├── stores/ ← Pinia stores（user/cart） │ │ │ ├── types/ ← TypeScript 类型 │ │ │ └── utils/ ← 工具函数 │ │ └── index.ts │ │ │ ├── web/ ← Web 端 │ │ ├── package.json ← @shop/web │ │ ├── vite.config.ts │ │ ├── src/ │ │ │ ├── App.vue │ │ │ ├── main.ts │ │ │ ├── router/ ← Vue Router │ │ │ ├── pages/ ← 页面组件 │ │ │ ├── components/ ← Naive UI + 自定义组件 │ │ │ ├── layouts/ ← DefaultLayout / BlankLayout │ │ │ └── assets/ │ │ └── index.html │ │ │ └── mobile/ ← 小程序 / App 端 │ ├── package.json ← @shop/mobile (UniApp) │ ├── vite.config.ts │ ├── src/ │ │ ├── pages/ │ │ ├── components/ │ │ ├── stores/ ← import from @shop/shared 或本地 │ │ └── pages.json │ └── manifest.json

Web 端技术选型

层选型说明
框架Vue 3 + TypeScript与 admin 端统一
构建Vite 5极速 HMR
UI 库Naive UI现代风格，TS 原生，Tree Shaking
路由Vue Router 4标准 SPA 路由
状态Pinia + persist复用 shared 包定义
HTTPAxios与 admin 端统一拦截器
CSSSCSS + CSS Variables全局主题变量
图标Naive UI Icons + 自定义 SVG按需引入

Mobile 端技术选型

层选型说明
框架UniApp 3 + Vue 3保留跨端能力
构建Vite (uni-app 插件)—
UI 库Uni UI（替换 uview-plus）UniApp 官方，三端表现一致
状态Pinia + persist复用 @shop/shared 的 store 定义
HTTPuni.request 封装（同 shared 接口）保持与当前一致的请求层

Shared 包依赖关系

依赖方向
@shop/shared
API · Stores · Types
↓ 依赖 ↓
@shop/web
Vue 3 + Naive UI
@shop/mobile
UniApp + Uni UI

Shared 包包含

  • API 函数（类型安全的请求封装）
  • Pinia Store 定义（user, cart）
  • TypeScript 类型（共享 DTO / 实体）
  • 工具函数（格式化、校验）

Shared 包不包含

  • Vue 组件（Web/Mobile UI 完全不同）
  • 路由配置（两端路由体系不同）
  • 样式（两端设计系统独立）
  • HTTP Client 实例（Axios vs uni.request 各自封装）
