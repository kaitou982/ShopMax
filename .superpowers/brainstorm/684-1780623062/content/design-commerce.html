商品浮窗交互流程

主播端（Admin 后台）

  1. 直播间管理页 → 选择商品
  2. 点击"讲解中" → 状态变为 status=2
  3. 后端通过 WebSocket 广播 { type: "product", data: { productId, action: "highlight" } }
  4. 观众端收到推送 → 商品浮窗自动弹出
  5. 主播点击"取消讲解" → 浮窗自动收起

观众端行为

  • 进入直播间：底部显示商品列表入口（购物车图标 + 商品数）
  • 讲解推送：右下角自动弹出商品卡片浮窗
  • 点击浮窗：展开商品详情（图片/价格/规格）
  • 加入购物车：选择 SKU → 加入购物车
  • 立即购买：选择 SKU → 跳转确认订单页
  • 收起浮窗：滑动关闭或 15 秒后自动收起

后端接口设计

新增/修改接口

# 主播设置讲解商品
PUT /api/v1/live/products/{id}/explain
→ status: 2 (讲解中)
→ WebSocket 广播 product highlight

# 主播取消讲解
PUT /api/v1/live/products/{id}/unexplain
→ status: 1 (上架)
→ WebSocket 广播 product unhighlight

# 获取直播间商品列表（含讲解状态）
GET /api/v1/live/rooms/{roomId}/products
→ 含 live_price, product 详情, 讲解状态

# 直播间内加购（复用已有购物车接口）
POST /api/v1/cart/items
→ body: { productId, skuId, quantity, liveRoomId }

直播专属价格逻辑

  • lms_live_product.live_price 为直播专属价
  • 直播间内商品展示优先使用 live_price
  • 加购时如果来自直播间，记录 liveRoomId
  • 下单时自动使用 live_price（如果有效）
  • 直播结束后 live_price 失效，恢复原价

数据复用

  • 复用已有 LiveProduct 实体和 CRUD
  • 复用已有购物车/订单流程
  • 仅新增"讲解中"状态和 WebSocket 推送
