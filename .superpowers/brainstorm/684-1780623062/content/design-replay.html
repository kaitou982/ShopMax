录制流程

录制与回放完整流程
SRS ① 直播中 → 实时写入 FLV 到 /record/live/{roomId}.{timestamp}.flv
SRS ② 推流断开 → on_unpublish 回调
后端 ③ 收到回调 → 触发异步任务上传录制文件
后端 ④ 读取本地 FLV → 上传到 MinIO Bucket live-replay
后端 ⑤ 上传成功 → 更新 lms_live_room.replay_url + 计算时长
后端 ⑥ 删除本地 /record/ 中的临时文件
观众 ⑦ 直播列表 → 已结束 → 点击"观看回放" → 播放 MinIO FLV

异步上传任务

@Async("liveReplayExecutor")
public void uploadReplay(Long roomId,
        String localPath) {
    // 1. 读取本地 FLV 文件
    // 2. 上传到 MinIO
    String objectName = "room-" + roomId
        + "/" + formatDate() + ".flv";
    storageService.upload(
        "live-replay", objectName, file);

    // 3. 更新 DB
    String url = storageService.getAccessUrl(
        "live-replay", objectName);
    liveRoomMapper.updateReplayUrl(roomId, url);

    // 4. 删除本地文件
    Files.deleteIfExists(Path.of(localPath));
}

方案: 直播结束后异步转码
1. SRS 录制 FLV
2. 上传 MinIO 后触发 FFmpeg 转码
3. 生成 MP4 版本存入 MinIO
4. Mobile 端播放 MP4

# FFmpeg 转码命令
ffmpeg -i input.flv \
  -c:v libx264 -c:a aac \
  -movflags +faststart \
  output.mp4
