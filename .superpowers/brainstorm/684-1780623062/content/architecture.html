核心数据流

推流链路

  1. 主播在后台点击"开播" → 生成推流地址（含 Token）
  2. OBS 填入地址推流 → SRS 接收 RTMP 流
  3. SRS 回调 on_publish → 后端更新状态为"直播中"
  4. SRS 同时输出 HTTP-FLV + HLS

观看链路

  1. 观众进入直播间 → 建立 WebSocket 连接
  2. 播放器根据平台选择 HTTP-FLV 或 HLS
  3. 弹幕/点赞/礼物通过 WebSocket 双向通信
  4. 商品浮窗通过 API 获取 + WebSocket 推送更新

互动链路

  1. 发送弹幕 → WebSocket → Redis 限频 → 广播房间
  2. 点赞 → Redis 原子计数 → 每 10 次持久化
  3. 送礼 → 扣虚拟币 → 广播动画 → 记录消息

录制链路

  1. SRS 配置 FLV 录制 → 写入本地文件
  2. 直播结束后 → 回调 on_unpublish
  3. 后端触发录制文件上传到 MinIO
  4. 更新 replay_url，观众可回看
