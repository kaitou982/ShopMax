设计 · 前端播放器组件

自适应播放器：Web 用 mpegts.js (HTTP-FLV)，Mobile 用 HLS

播放器组件架构

Web 端 (packages/web)

// components/LivePlayer.vue
<script setup lang="ts">
import { ref, onMounted, onUnmounted } from 'vue'
import mpegts from 'mpegts.js'

interface Props {
  roomId: number
  url: string          // HTTP-FLV 地址
  autoplay?: boolean
  muted?: boolean
}

const props = withDefaults(
  defineProps<Props>(),
  { autoplay: true, muted: true }
)

const videoRef = ref<HTMLVideoElement>()
let player: mpegts.Player | null = null

const initPlayer = () => {
  if (!mpegts.isSupported()) {
    // 降级到 HLS
    fallbackToHls()
    return
  }
  player = mpegts.createPlayer({
    type: 'flv',
    isLive: true,
    url: props.url,
  })
  player.attachMediaElement(videoRef.value!)
  player.load()
  player.play()
}
</script>

播放器核心能力

自动降级

  • Web: HTTP-FLV → HLS 兜底
  • Mobile: HLS 直接播放
  • 小程序: 原生 <video> HLS

直播状态感知

  • 加载中 → 显示 loading
  • 播放中 → 显示 LIVE 标记
  • 已结束 → 显示"直播已结束"
  • 断流 → 自动重连（3 次）

交互控制

  • 静音/取消静音
  • 全屏切换
  • 清晰度切换（如有多路）
  • 横竖屏适配
