主播推流方式

主播（店家）通过什么方式把画面推送到服务器？

A

OBS Studio 推流（推荐）

主播使用 OBS Studio 软件，填入推流地址即可开播

工作流程

  1. 主播在 ShopMax 后台点击"开播"
  2. 系统生成 RTMP 推流地址（含鉴权 Token）
  3. 主播将地址填入 OBS → 开始推流
  4. SRS 检测到流 → 后端自动更新状态为"直播中"
  5. 观众在前端看到直播画面

优势

  • 实现简单，OBS 是行业标准工具
  • 支持摄像头+屏幕+图片叠加，功能强大
  • 推流质量高，可调分辨率/码率/帧率
  • 主播端零开发工作量

劣势

  • 主播需要安装 OBS 软件
  • 移动端主播不方便
B

浏览器网页推流

主播在 ShopMax 网页上直接开播，无需安装任何软件

工作流程

  1. 主播在后台点击"开始直播"
  2. 浏览器请求摄像头/麦克风权限
  3. 通过 WebRTC/MediaRecorder 采集音视频
  4. 通过 WHIP 协议推流到 SRS
  5. 观众端拉流观看

优势

  • 零安装，打开网页就能播
  • 移动端主播友好
  • 体验更流畅

劣势

  • 实现复杂（WebRTC + WHIP）
  • 推流质量受浏览器限制
  • 不支持画面叠加/特效
  • SRS 对 WHIP 支持需要额外配置
C

两种都支持

OBS 推流为主 + 网页推流为辅，给主播更多选择

注意

  • 开发工作量翻倍
  • 建议先做 OBS，网页推流作为后续迭代

我的建议

选 A（OBS 推流）。原因：

  • 这是电商直播的标准做法（淘宝/抖音直播都用 OBS 或定制推流工具）
  • 实现简单可靠，后端只需生成推流地址 + 监听 SRS 回调
  • 网页推流可以作为 v2 迭代
