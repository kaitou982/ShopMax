- **用户体系** — 会员等级自动升级、积分/余额/成长值流水

## 六、建议修复优先级

### 🔴 高优先级（影响核心流程）

1. **微信支付接入** — 当前为 Mock，上线前必须接入真实 SDK
2. **订单超时取消** — 无超时机制会导致库存长期锁定
3. **订单操作日志** — 审计追溯的必要能力
4. **Dashboard 对比指标** — 当前硬编码为 0，无实用价值
5. **Banner 管理页面** — 后端接口已就绪，仅需前端页面

### 🟡 中优先级（影响功能完整性）

6. **搜索接入 Elasticsearch** — MySQL LIKE 在数据量增长后性能堪忧
7. **直播 SDK/播放器** — Web 和 Mobile 端均无真正直播体验
8. **物流跟踪** — P1 功能完全缺失
9. **积分商城** — 有积分体系但无消费出口
10. **商品评价独立 Service + 审核**

### 🟢 低优先级（可后续迭代）

11. 砍价/分销/签到/发票/实名认证
12. 达人体系/短视频/直播回放/直播数据分析
13. 店铺装修/店铺数据分析
14. 个性化推荐算法
